# دليل أقسام الهندسة الميكانيكية

موقع عربي تفاعلي للتعريف بأقسام كلية الهندسة الميكانيكية، مع واجهة RTL احترافية وتجربة تصفح مناسبة للهاتف وسطح المكتب.

## المزايا
- عرض الأقسام الثمانية في بطاقات تفاعلية.
- نافذة تفصيلية لكل قسم دون مغادرة الصفحة.
- هوية بصرية زيتونية مع خلفية ديناميكية.
- توافق مع الشاشات الصغيرة والكبيرة.
- احترام إعداد تقليل الحركة.

## التشغيل محلياً
افتح ملف `index.html` مباشرة في المتصفح.

## النشر
يمكن تفعيل GitHub Pages من فرع `main` وجذر المستودع.
